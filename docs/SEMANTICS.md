# Exact contract, version 1.0

A `World` is a frozen tuple of entities, declared relation signatures, fact occurrences, local aliases, and episode source strings. Parsing creates detached immutable dataclasses. Structural and episodic modes are disjoint. Generated entities share the `node` sort, while four relation types have explicit `node -> node` signatures; the engine also supports heterogeneous declared sorts and rejects ill-typed edges. It does not claim four distinct entity sorts.

Every edge contains a unique internal edge ID, public subject/relation/object names, a batch integer, an optional internal episode reference, and a positive **visible occurrence ordinal**. Ordinals must be unique within a source episode (or the structural graph). The same triple may occur more than once, including inside the same episode, provided occurrences differ. Episodes have unique public cues. Alias bindings are `(alias, entity, episode)` facts; duplicate identical bindings are rejected, but one alias may legitimately bind several entities in one or several scopes.

`atomic(start, r)` returns all `o` for source facts `(s,r,o)` whose subject and scope satisfy `start`. For an entity start, `s` is that entity; a supplied cue additionally restricts the episode. For an alias start, the alias must bind `s` **in the first fact's episode**; a supplied cue restricts that episode. It is not correct to resolve an alias globally and then use the resolved entity's edges in every other episode.

`join(start, [r1,r2], episode_constraint)` enumerates every ordered pair `(s,r1,m)`, `(m,r2,o)` with a compatible first fact. The two declared relation signatures must be satisfied by their source edges; no coercion or implicit type conversion occurs. For `distinct`, their episode IDs must differ. The optional `first_cue` must equal the start scope; optional `second_cue` restricts the second fact to its named public bundle. In the primary L5 corpus both cues are explicit and distinct. The answer set contains every `o`; proofs contain every ordered edge pair and every binding witness, even when several yield the same endpoint. Ordinary relational composition can reuse an edge when the equalities and relation labels permit; `distinct` excludes such reuse.

`all_matching(start, r)` returns one public event value per matching occurrence: `cue` (null for a structural graph), `occurrence`, `subject`, `relation`, `object`. Duplicate facts never disappear merely because their triples agree. Alternative answer orderings are valid. Predictions with duplicate set elements are malformed; missing or invented events affect recall or precision respectively.

`reconstruct(cue)` returns exactly one stored source string after verifying the cue is public and unique. The release validator rerenders each source from immutable edges, alias declarations and symbol payloads before accepting source labels. This connects the formal world to the rendered bytes; the low-level world API permits arbitrary source text for direct reconstruction tests. No source reconstruction is inferred from model output.

The production implementation loops over raw edges and edge pairs. The SQLite implementation independently loads fact, binding and episode tables and uses relational joins to derive target values and every witness. They share the input dataclasses and strict parser, not traversal/binding/answer helpers. Exhaustive tests therefore validate evaluator agreement but cannot alone prove the shared parser or intended semantics; explicit adversarial and hand-computed tests cover those separately.

JSON object fields are exact for worlds and queries. Unknown IDs, relation signature violations, duplicate object keys/IDs/ordinals, unexpected fields, invalid Unicode, nonfinite JSON numbers, and booleans or floats used in integer positions are rejected. Sets are deterministically serialized in sorted canonical JSON order. No probabilities occur, so zero-probability arithmetic is not applicable; empty-answer cases are tested exhaustively.

# Paired controls

L3 uses 64 entities in groups of eight (16 for topology OOD). Each relation has four active sources and four active destinations per group of eight, each with two outgoing/incoming facts. Destination permutations across groups turn zero bridge facts into 256 while preserving every entity's indegree and outdegree for each relation, source length, total token frequency and batch assignments. All ordered two-relation query pairs are represented. Labels are never consulted when choosing worlds or queries.

L5 uses 32 bundles of 64 **whitespace** tokens. Each has four local entity bindings, eight visible fact occurrences and 17 symbol tokens. A bundle's eight edge endpoints use every local entity four times, so alias declarations plus facts preserve global entity multiplicities under all five interventions. Every public entity appears in exactly two bundles.

The five frozen cells are `base=(0,0,0,0)`, `overlap=(1,0,0,0)`, `aliases=(0,1,0,0)`, `distractors=(0,0,1,0)`, `compressibility=(0,0,0,1)` in overlap/collision/density/compression order. Maximum pairwise entity overlap changes from two to four. Each alias token occurs twice: the collision intervention changes it from one to two bound entities while retaining distinct local alias tokens. The density intervention changes the designated first relation from one to two outgoing alternatives while preserving total endpoint and relation-token frequency; it is a **branching-distractor** control, not a larger number of source facts. Compression permutes a fixed symbol multiset independently by episode, preserving token counts but changing byte compressibility.

The baseline compression grammar and the shuffled-symbol corpus share the same random relational facts. This narrow compression control changes an explicit source payload, not latent semantic entropy. Zlib byte differences are measured, not treated as evidence about a neural memory capacity law. Answer-set cardinality distributions and their Shannon entropy are reported; equality is not assumed. Empirical entropy of exact answer values is separately reported by query kind; it is not a certified balanced population distribution. Both full whitespace-token counters and identifier-lexeme counters are checked across paired sources.

Semantic contract 1.2 additionally freezes query-kind retrieval budgets and support-cover diagnostics; see EXPERIMENT_INTERFACE.md. Primary L5 joins test scoped composition, not second-source discovery.
